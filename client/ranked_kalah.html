Waktu: 28 detik

Diketahui matriks A = [[3, 2], [1, 4]]. Nilai dari det(A) dan elemen diagonal utama dari invers matriks A berturut-turut adalah:

close
Jawabanmu: Opsi B: det(A) = 14; Elemen = 4/14 dan 3/14 Catatan: Terjadi kekeliruan perhitungan (ad - bc). 3×4 - 2×1 = 10, bukan 14.
check_circle
Jawaban Benar: Opsi D: det(A) = 10; Elemen = 4/10 dan 3/10 Rumus invers A¯¹ = 1/det(A) × adj(A). Elemen diagonal utama ditukar posisi.

Waktu: 42 detik (Time Limit)

Jika matriks M memiliki baris pertama [2, 0, 1], baris kedua [1, 3, 2], dan baris ketiga [0, 4, -1], tentukan nilai |M|:

close
Jawabanmu: Opsi A: |M| = -14 Tanda minus pada perkalian diagonal minor terlewatkan saat reduksi cepat.
check_circle
Jawaban Benar: Opsi C: |M| = -22 Sarrus: (2×3×-1 + 0×2×0 + 1×1×4) - (0×3×1 + 4×2×2 + -1×1×0) = (-6 + 4) - (16) = -2 - 16 = -18 (atau ekspansi kofaktor kolom 1: 2(-11) - 1(-4)).
tips_and_updates Tips Cepat: Gunakan ekspansi baris dengan angka 0 terbanyak untuk menghemat waktu pengerjaan 50%.
